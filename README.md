# IDPhoto
电子证件照处理工具：上传一张照片，换底色（蓝 / 白 / 红 / 灰 / 黑）、裁切到一寸 / 两寸标准尺寸、可调分辨率(DPI) 与输出文件大小(KB)，一键生成证件照。Python + Pillow，带图形界面和命令行两种模式。  ID photo tool: pick a photo, change background (blue/white/red/gray/black), crop to 1-inch / 2-inch standard size, adjust DPI resolution and output file size (KB), one-click export. Python + Pillow, GUI and CLI.
